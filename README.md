# Пепел и гоблины

Личный дневник тренировок по годовому плану на 52 недели (12.10.2026 – 10.10.2027) (гири, турник, брусья) в виде souls-like RPG: каждая тренировка — монстр, каждый подход наносит ему урон.

Сайт статический (GitHub Pages), работает как приложение на Android и открывается без интернета. Claude для работы не нужен: всё, включая подсказки по прогрессу, считается прямо в браузере.

## Как пользоваться

- **Бой** — тренировка дня. Тап по пустой клетке записывает подход по плану, повторный тап открывает правку числа, «+» добавляет подход сверх плана. Под упражнением — вес (например, «гиря +16 кг») и заметка. В конце — «Завершить бой».
- **Поход** — все недели, серия, заморозки, монстры каждого дня.
- **Прогресс** — подсказки (застой, недобор, перевыполнение, спад, боль в заметках), выполнение плана по неделям, графики по упражнениям, личные рекорды.
- **Герой** — уровень, достижения, бестиарий, правила прокачки.

## Правила игры

- Здоровье монстра = плановый объём дня (30 за каждый плановый подход, не больше 5 подходов на упражнение). Полностью выполненный план = монстр повержен.
- Перевыполнение даёт бонусный опыт, но не больше +20% здоровья. Личный рекорд = критический удар.
- Не добил — монстр сбегает раненым, опыт за урон остаётся.
- Вес не как в плане — урон пересчитывается пропорционально нагрузке. Со своим весом нагрузка = вес тела (`meta.bodyweight`, по умолчанию 96) + отягощение − резинка.
- Реванш: сбежавший монстр приходит вместо монстра следующей обычной тренировки (если она в течение 14 дней). Добил — убийство засчитывается (и для зачистки подземелья за день побега), +50 опыта. Возвращается один раз. Боссы и таверна не возвращаются.
- Своя тренировка («Вышло не по плану» внизу дня): **дополнить** — свои упражнения к плановым, идут в перебор (общий потолок +20%); **заменить** — каждый свой подход бьёт монстра как плановый, но не больше 70% здоровья: убить можно только планом, монстр сбегает и приходит на реванш, неделя для серии засчитывается; **отдельным днём** — вылазка вне плана: +2 опыта за подход, не больше 30 в день, без золота, находок и серии. Любое плановое упражнение можно заменить другим (кнопка «заменить» у упражнения): повторы сравниваются с плановыми, но замена даёт не больше 70% урона этого упражнения, так что монстр в этот день сбегает на реванш. Рекорды в своих и заменённых упражнениях записываются в историю и графики, но крита (опыта) не дают; названия лучше брать из подсказок (как в плане), тогда рекорды и графики общие.
- Блоки плана — подземелья, тесты — боссы, лёгкие/разгрузочные недели — таверна (серия не рвётся).
- Серия считается по неделям: неделя засчитана, если проведены все обязательные силовые. 3 ручные заморозки на план.
- Награды (Летопись): за достижения, новые титулы и первое убийство вида. Забираются кнопкой и действуют с этого дня: золото, опыт, бафы на несколько дней (Вдохновение +15% опыта, Золотая лихорадка +30% золота, Счастливый след +8% к находкам; повтор продлевает срок), изученный вид (+2% опыта в боях с ним). Часть достижений вместо награды даёт почётный титул: носится один, его эффект работает, пока он надет. За серии 16 и 26 недель, «Склеп запечатан», Древнего дракона и титул «Легенда» — уникальные вещи (+1 к характеристике и два эффекта, слабее легендарок). За идеальный год награды дают ≈ +4% опыта и ≈ +16% золота.

## Сохранение данных

Записи сразу сохраняются в браузере телефона. Если в «Настройках» указан токен GitHub, копия уходит в этот репозиторий, в ветку **`data`**:

```
data/log/2026-10-28.json   — одна тренировка (дата из плана)
data/meta.json             — заморозки серии (freezes) и переносы тренировок (shifts: at = дата по плану, days = на сколько дней, scope = one | all)
                             и билд героя (build.log = [{at: дата, stats: {str,end,agi,wil,lck}, nodes: [id узлов древа]}], build.respecs = блоки, где был сброс;
                             gear.log = [{at: дата, eq: {weapon, armor, amulet, ring: id вещи}}], вещь целиком выводится из id;
                             shop.log = [{at: дата, act: buy | forge | mythic, id: новая вещь, use: [id израсходованных], cost: золото}];
                             rewards.log = [{at: дата, id: a:<достижение> | t:<номер титула> | m:<монстр>}] — забранные награды;
                             honor.log = [{at: дата, id: достижение почётного титула | "" — титул уровня}])
```

Формат записи тренировки:

```json
{
  "date": "2026-10-28",           // дата дня в плане
  "week": 3, "block": "Блок 1. Возвращение", "title": "Б — жим + одна нога",
  "performedOn": "2026-10-28",    // когда тренировка была на самом деле
  "finished": true, "finishedAt": "2026-10-28T19:40:00.000Z",
  "dayNote": "заметка о тренировке",
  "items": [
    { "type": "ex", "name": "Отжимания на брусьях (основные)", "plan": "5×6",
      "planWeight": "свой вес", "weight": "свой вес", "reps": [6, 6, 6, 5, 5], "note": "" },
    { "type": "note", "text": "Скакалка 10×(1 мин / 1 мин)", "done": true }
  ],
  "game": { "monster": "Гоблин-лучник", "hp": 630, "dealt": 600, "overkill": 0, "killed": false },
  "updatedAt": 1793200000000
}
```

Своя тренировка: `extra: [{ "name", "weight", "reps": [...], "note" }]` — свои упражнения дня; `items[i].sub` — чем заменено плановое упражнение (вес тогда в `weight`); `replaced: true` — день заменён своей тренировкой (плановые `reps` тогда не считаются). Вылазка вне плана — отдельный файл `data/log/x-2026-10-30.json` (второй за день — `x-2026-10-30-2`) с полями `date` (= ключ), `sortie: true`, `title`, `performedOn`, `finished`, `dayNote`, `extra`; удалённая помечена `deleted: true`.

`items` идут в том же порядке, что и в плане (`plan.js`). `reps` — повторы по подходам (для планки и скакалки — секунды или минуты, как в плане); `null` — пропущенный подход.

### Токен

github.com → Settings → Developer settings → Fine-grained tokens → Generate: доступ только к репозиторию `training`, права **Contents: Read and write**. Токен хранится только в браузере телефона.

## Файлы

| файл | что внутри |
|---|---|
| `plan.js` | план тренировок (недели, дни, упражнения). Длина плана любая: можно дописать недели |
| `game.js` | монстры, урон, опыт, рекорды, серии, достижения |
| `analysis.js` | встроенный анализ и подсказки |
| `store.js` | хранение на телефоне и синхронизация с GitHub |
| `app.js`, `index.html`, `style.css` | интерфейс |
| `sw.js`, `app.webmanifest` | офлайн и установка. После изменения файлов поднять `VERSION` в `sw.js` |
| `assets/monsters/` | картинки монстров. Боссы и хозяин таверны пока силуэты: положить `boss-goblin-king.webp`, `boss-orc-warlord.webp`, `boss-ancient-dragon.webp`, `tavern-keeper.webp` и поправить `MONSTERS` в `game.js` |
